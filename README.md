# Wild World — Дикий мир 🌿

Первая версия собственной трёхмерной приключенческой игры.

## Что уже есть
- 3D-поляна с лесом, цветами, камнями, тропинкой и домиком.
- Управляемый мультяшный лисёнок.
- Камера сверху-сзади и сглаженный рендеринг.
- Виртуальный джойстик для телефона и WASD/стрелки на компьютере.
- Сбор синих ягод, староста, задания и монеты.
- Интерфейс, подстроенный под мобильный экран.

## Запуск
Проект использует Three.js с CDN, поэтому для запуска нужен интернет. После публикации открой сайт GitHub Pages. Можно также открыть `index.html` через локальный веб-сервер.

## Публикация на GitHub Pages
В репозитории открой **Settings → Pages** и выбери **GitHub Actions** в разделе Build and deployment. Workflow в `.github/workflows/pages.yml` автоматически публикует сайт при изменениях в ветке `main`.
